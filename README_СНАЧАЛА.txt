NEFOR SPOT — резервное копирование Neon / PostgreSQL

Содержимое архива:
  salon_cost_bot/backups.py                 — новый экспорт полной резервной копии Neon
  salon_cost_bot/handlers/admin.py          — админка с предыдущими исправлениями + кнопка Neon
  scripts/restore_neon_backup.py            — АВАРИЙНОЕ восстановление в НОВУЮ ПУСТУЮ базу

УСТАНОВКА (ветка dev, не main):
  1. В GitHub Desktop выберите dev.
  2. Распакуйте архив в папку репозитория, с заменой файлов.
  3. В GitHub Desktop: Commit to dev -> Push origin.
  4. НЕ нажимайте Merge to main до проверки.

После проверки и осознанного выпуска в main:
  Администратор -> Экспорт -> Резервная копия Neon.
  Бот отправит nefor-neon-backup-ДАТА.json.gz.
  Сохраните файл отдельно (не в репозитории GitHub):
  в нём содержатся имена клиентов, Telegram ID, история и закупочные цены.

Формат JSON.GZ — собственная логическая резервная копия приложения,
не стандартный pg_dump. Создаётся из согласованного снимка таблиц Neon.
На данный момент экспорт охватывает все 11 таблиц схемы версии 1.
Если схема изменится (появятся таблицы), архив не будет создан молча неполным.

ВОССТАНОВЛЕНИЕ (только при аварии, НЕ сейчас):
  - Создайте ОТДЕЛЬНУЮ новую ПУСТУЮ базу PostgreSQL/Neon.
  - На защищённом компьютере с зависимостями приложения задайте
    NEON_RESTORE_DATABASE_URL со строкой подключения именно этой новой базы.
  - Выполните: python scripts/restore_neon_backup.py ПУТЬ_К_АРХИВУ.json.gz --confirm-empty-target
  - Скрипт проверит формат и контрольные суммы, схему, пустоту всех таблиц,
    восстановит записи и последовательности ID в одной транзакции.
  - Никогда не передавайте секреты БД в чат или GitHub.
  - После восстановления отдельно проверьте функциональность на новой базе.

ОГРАНИЧЕНИЯ / МЕРЫ БЕЗОПАСНОСТИ:
  - Экспорт НЕ выполняет автоматические бэкапы по расписанию: нужно нажать кнопку.
  - Архив нужно хранить вне Telegram/GitHub и не выкладывать публично.
  - Ничего не меняет в рабочем Neon до выкладки через main.
  - Дамп предназначен для схемы v1 проекта. Перед реальным восстановлением
    проверьте версию исходного приложения и данные на тестовой базе.
  - Если архив превышает лимит Telegram Bot API, отправка файла может не пройти.
