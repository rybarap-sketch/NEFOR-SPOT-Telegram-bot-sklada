NEFOR SPOT — завершение окрашивания с расчётом мастера и салона

1. В GitHub Desktop переключитесь на MAIN и убедитесь, что нет незакоммиченных изменений.
2. Скопируйте папку salon_cost_bot из архива в КОРЕНЬ проекта рядом с main.py.
   Замените четыре существующих файла и добавьте payouts.py.
   Не копируйте отдельные файлы из zip в корень: нужно сохранить структуру.
3. В GitHub Desktop проверьте список изменений.
4. Проверка без доступа к Neon: py -m compileall -q salon_cost_bot
   (Запускать самого бота с тем же Telegram-токеном на компьютере НЕ НУЖНО.)
5. После просмотра изменений сделайте Commit to main -> Push origin.
   Render должен получить обновление через настроенный автодеплой.
6. Проверка в Telegram: создать ТЕСТОВЫЙ расчёт с небольшим расходом,
   ввести цену, увидеть предпросмотр. Нажать «Отмена» — остатки не меняются.
   Реальное сохранение тестировать только на согласованном материале,
   поскольку оно спишет граммы в рабочей Neon.

ВАЖНО:
* Ставки: мастеру 55%, салону 45%. Расходники вычитаются ПЕРЕД процентами.
* Сумма «передать салону» предполагает, что мастер получил 100% оплаты клиента.
* Проценты зафиксированы в файле salon_cost_bot/payouts.py и в истории операции.
* Цена ниже расходников не принимается — мастер должен исправить ввод.
* Миграция только ДОБАВЛЯЕТ таблицу calculation_settlements.
  Старые остатки, история и расчёты не удаляются.
* Новый расчёт, расход материалов и сохранение долей происходят в ОДНОЙ транзакции.
* Старые расчёты сохраняются без данных о распределении, это нормально.
* Не включайте одновременно локального бота и Render с одним BOT_TOKEN.
* Перед размещением в main просмотрите реальные изменения и убедитесь,
  что это актуальная версия файлов, а не перезапись более свежих изменений.
